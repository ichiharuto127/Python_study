# 問題1
変数aの値が3で割り切れるときには「3で割り切れます」、そうでないときには「3で割り切れません」とコンソールに出⼒するプログラムを完成させよ。

# 解答
a = 2026
if a % 3 == 0:
    print("3で割り切れます")
else:
    print("3で割り切れません")

*インデントは空白4つ分*

# 問題2-1
10から20までの整数を順番に⾜し合わせて、その結果を出
⼒するプログラムを作れ。
ただし、while⽂を使った場合とfor⽂を使った場合の2つのプログラムコードを作成せよ。

# 解答
*while文*
total = 0
i = 10
while i < 21:
    total += i
    i += 1
print(total)

*for文*
total = 0
for i in range(10, 21):
    total += i
print(total)

# 問題2-2
問題2-1で作成したfor⽂を使ったプログラムコードに対して、15だけは⾜し合わせしないように、変更せよ。

# 解答
total = 0
for i in range(10, 21):
    if i == 15:
        continue
    total += i
print(total)
