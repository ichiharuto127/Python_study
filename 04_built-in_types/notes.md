# 問題1
・Pythonは [ (1) ] 指向型の⾔語であり、クラスは[ (1) ]の属性や機能を定義したものです。
• 'Hello'や'Python'といった⽂字列はstr型のオブジェクトですが、別の表現をすると、strクラスの [ (2) ] である、ということができます。
• strクラスには、⽂字列に含まれる⽂字を⼩⽂字に変換するlowerという[ (3) ]があります。
• a == bという式の値がTrueであったとき、aとbは [ (4) ] であるといい、a is bという式の値がTrueであったとき、aとbは [ (5) ] であ
るといいます。

# 解答
