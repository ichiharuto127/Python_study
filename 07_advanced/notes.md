# 問題1
次のコードは、リストに含まれる⽂字列を1つだけ出⼒する。どの⽂字列を出
⼒するかは、ユーザーが⼊⼒する値をインデックスに使⽤して決める。⼊⼒し
た値が0、1、2のいずれかの場合には正しく動作するが、そうでない場合には
エラーが発⽣してしまう。
try〜except 構⽂を使⽤して、次のような例外処理を追加せよ。
・⼊⼒した値が数字でない場合（ValueErrorが発⽣します）に「数字が⼊⼒さ
れませんでした」と出⼒する
・数字であってもインデックスの範囲を超えている場合（IndexErrorが発⽣し
ます）には、「範囲外の値が⼊⼒されました」と出⼒する

# 解答
l = ['リンゴ', 'バナナ', 'オレンジ']
a = input('好きな整数を入力してください:')
try:
    print(l[int(a)])
except ValueError:
    print('数字が入力されませんでした')
except IndexError:
    print('範囲外の値が入力されました')
