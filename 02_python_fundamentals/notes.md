# 第2章 練習問題

# 問題1
(1) ⼀度int型の値を代⼊した変数aに対して、後から⽂字列を代⼊することはできない。
(2) int型の値とfloat型の値を加算するときには、その前にint型の値をfloat型に型変換しておく必要がある。
(3) int型とfloat型の値を含む算術演算の結果はfloat型になる。
(4) a = int(3.8)と記述した場合、変数aの値は4になる。

# 解答
(1) ○
Pythonは動的言語であるため、あとから別の型の値を自由に代入できる。

(2) ×
Pythonでは自動で型変換をするのでそのまま計算できる。

(3) ○
アップキャスト(型の昇格)によりfloat型を含む演算はすべてfloat型で返す。また、int型同士の除算でもfloat型で返す。

(4) ×
int() による変換は小数点以下を切り捨てて返す。

# 問題2
mathモジュールを利用して、cos(120°)の値を求めよ。

# 解答
import math as m
print(m.cos(m.radians(120)))
